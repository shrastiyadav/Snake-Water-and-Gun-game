# 🐍 Snake, Water, Gun Game

A simple command-line Python game based on the classic **Snake, Water, and Gun** logic. Similar to Rock, Paper, Scissors — this game is fun, beginner-friendly, and a great way to practice basic Python skills like conditionals, loops, and randomization.

---

## 🎮 Game Rules

- Snake drinks water 🐍 > 💧
- Gun shoots snake 🔫 > 🐍
- Water damages gun 💧 > 🔫
- If both choose the same — it's a draw.

---

## 🚀 How to Run

Make sure Python is installed on your system.

```bash
python snake_water_gun.py
